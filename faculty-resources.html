How to use it in Canvas

  1. Create a new assignment in your course and open its description editor.
  2. Switch the editor to HTML, then paste the copied code.
  3. Return to the visual editor. Replace the bracketed instructor fields with your points, deadline, submission method, and any course-specific requirements.
  4. Configure the assignment’s points, extra credit grading approach, submission type, and due date in Canvas to match your instructions. The template suggests a text-entry submission.
  5. Preview the assignment as a student, remove any unused placeholders, then publish.

Using a Canvas page instead? Paste the same HTML into the page’s HTML editor and explain how students should submit their attendance details.
